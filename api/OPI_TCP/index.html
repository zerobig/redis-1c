TCP (ОПИ) (OPI_TCP)

Методы модуля​

ОткрытьСоединение​

Открыть соединение !NOCLI Создает TCP соединение

Параметры метода

  • Адрес
    • Строка - Адрес и порт для подключения - address
  • Tls
    • Структура Из КлючИЗначение - Настройки TLS, если необходимо. См. ПолучитьНастройкиTls - tls
  • Прокси
    • Структура Из КлючИЗначение - Настройки прокси, если необходимо. См. ПолучитьНастройкиПрокси - proxy

Возвращает

Соответствие Из КлючИЗначение - Возвращает объект TCP клиента при успешном подключении или информацию об ошибке

ЗакрытьСоединение​

Закрыть соединение !NOCLI Явно закрывает созданное ранее соединение

Параметры метода

  • Соединение
    • Произвольный - Соединение, См. ОткрытьСоединение - tcp

Возвращает

Булево - всегда возвращает Истина

ПрочитатьДвоичныеДанные​

Прочитать двоичные данные !NOCLI Читает данные из указанного соединения

Примечание: При работе с бесконечным потоком входящих данных обязательно указание параметра МаксимальныйРазмер, так как^^ бесконечное получение данных может привести к зависанию При закрытии соединения, ошибке или обнаружении EOF чтение завершается в любом случае

Параметры метода

  • Соединение
    • Произвольный - Соединение, См. ОткрытьСоединение - tcp
  • МаксимальныйРазмер
    • Число - Максимальный размер данных (байт). 0 > без ограничений - size
  • Маркер
    • Строка - Маркер конца сообщения. Пусто > без маркера - marker
    • ДвоичныеДанные - Маркер конца сообщения. Пусто > без маркера - marker
  • Таймаут
    • Число - Таймаут ожидания данных (мс). 0 > без ограничений - timeout

Возвращает

ДвоичныеДанные - Полученные данные

ПрочитатьСтроку​

Прочитать строку !NOCLI Читает данные из указанного соединения в виде строки

Примечание: При закрытии соединения, ошибке или обнаружении EOF чтение завершается в любом случае

Параметры метода

  • Соединение
    • Произвольный - Соединение, См. ОткрытьСоединение - tcp
  • Кодировка
    • Строка - Кодировка преобразования данных в строку - enc
  • Маркер
    • Строка - Маркер конца сообщения. Пусто > без маркера - marker
    • ДвоичныеДанные - Маркер конца сообщения. Пусто > без маркера - marker
  • Таймаут
    • Число - Таймаут ожидания данных (мс). 0 > без ограничений - timeout

Возвращает

Строка - Полученные данные в виде строки

Параметры метода

  • Соединение

ОбработатьЗапрос​

Обработать запрос Отправляет одиночный запрос на указанный адрес и получает ответ, используя стандартные настройки

Параметры метода

  • Адрес
    • Строка - Адрес и порт для подключения - address
  • Данные
    • Строка - Данные или текст для отправки - data
    • ДвоичныеДанные - Данные или текст для отправки - data
  • ОтветСтрокой
    • Булево - Признак получения ответа как строки - string
  • Tls
    • Структура Из КлючИЗначение - Настройки TLS, если необходимо. См. ПолучитьНастройкиTls - tls
  • Прокси
    • Структура Из КлючИЗначение - Настройки прокси, если необходимо. См. ПолучитьНастройкиПрокси - proxy

Возвращает

ДвоичныеДанные - Ответ на запрос или информация об ошибке

ПолучитьПоследнююОшибку​

Получить последнюю ошибку !NOCLI Получает информацию о последней ошибке в соединении

Параметры метода

  • Соединение
    • Произвольный - Соединение, См. ОткрытьСоединение - tcp

Возвращает

Соответствие Из КлючИЗначение - Информация об ошибке или неопределено, если ошибки нет

ПолучитьНастройкиПрокси​

Получить настройки прокси Формирует структуру настроек прокси-сервера для соединения

Параметры метода

  • Адрес
    • Строка - Адрес прокси - addr
  • Порт
    • Число - Порт прокси - port
  • Вид
    • Строка - Вид прокси: socks5, socks4, http - type
  • Логин
    • Строка - Логин авторизации, если необходимо - login
    • Неопределено - Логин авторизации, если необходимо - login
  • Пароль
    • Строка - Пароль для авторизации, если необходимо - pass
    • Неопределено - Пароль для авторизации, если необходимо - pass

Возвращает

Структура Из КлючИЗначение - Структура настроек прокси

ПолучитьНастройкиTls​

Получить настройки TLS Формирует настройки для использования TLS при выполнении запросов

Примечание: Настройки Tls могут быть установлены только в момент создания соединения: явного, при использовании функции ОткрытьСоединение^^ или неявного, при передаче строки подключения в метод ОбработатьЗапрос

Параметры метода

  • ОтключитьПроверкуСертификатов
    • Булево - Позволяет работать с некорретными сертификатами, в т.ч. самоподписанными - trust
  • ПутьКСертификату
    • Строка - Путь к корневому PEM файлу сертификата, если его нет в системном хранилище - cert

Возвращает

Структура Из КлючИЗначение - Структура настроек TLS соединения
